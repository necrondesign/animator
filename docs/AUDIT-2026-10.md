## 1. Что это за продукт

**Haiku Animator** — десктопное Electron-приложение для анимации **импортированной**
векторной графики на таймлайне. Своих инструментов рисования в UI нет: графику
берут из Sketch, Figma, Illustrator или SVG и оживляют. Идея авторов: готовые для
продакшена анимации и UI-компоненты без передачи «дизайнер → разработчик».

### Четыре реальных сценария

| # | Сценарий | Как реализовано | Состояние |
|---|---|---|---|
| 1 | **Lottie для iOS/Android/веба** | `haiku-formats/src/exporters/bodymovin` (1600 строк, есть golden-тесты). При каждом сохранении пишется `code/<comp>/lottie.json` | Работает, но с ограничениями (см. §5) |
| 2 | **Интерактивные веб-компоненты** (vanilla, React, Vue, Angular) | Проект — это npm-пакет; рантайм `@haiku/core` (MIT) проигрывает «bytecode» | Рантайм работает; адаптеры устарели (React без хуков, Angular 6) |
| 3 | **GIF / MP4** | Невидимое окно Electron делает скриншот каждого кадра (`capturePage`), потом ffmpeg | Работает только на macOS (меню Export закрыто для других ОС) |
| 4 | **Импорт из дизайн-тулов** со связью с исходником | Sketch: CLI `sketchtool`; Illustrator: ExtendScript `.jsx`; Figma: REST API + OAuth | **Figma сломан** (обмен токена шёл через сервер Haiku); Sketch только macOS |

### Ключевые возможности

- **Сцена (`haiku-glass`)**: перемещение, масштаб и поворот, точка трансформации,
  снаппинг, редактирование вершин и bezier-ручек (морфинг), группировка, выравнивание.
- **Таймлайн (`haiku-timeline`)**: keyframes, твины, около 30 easing-кривых, редактор
  bezier-кривой, frame actions.
- **Expressions**: любое свойство может быть функцией от `$user` (мышь/тач), `$time`,
  `$state`, `$window` и т.д.; есть условия, повторы и плейсхолдеры (`$if`, `$repeat`).
- **States + Actions**: состояния компонента и обработчики событий с редактором кода
  (Monaco).
- **Вложенные компоненты** со своими таймлайнами, **Preview-режим**, undo/redo.
- **Версионирование проекта** через локальный git (nodegit, автокоммиты).

### Архитектура (кратко)

```
Electron main (index.js)
 └─ fork → HaikuHelper.js → haiku-plumbing (WebSocket-сервер, порт 1024, «Envoy»)
 └─ BrowserWindow: haiku-creator (React 15)
      ├─ <webview> haiku-glass     (сцена)       ─┐ каждый держит свою копию модели
      └─ <webview> haiku-timeline  (таймлайн)    ─┘ haiku-serialization, синхронизация через WS
```

Формат проекта — обычная папка: `code/<component>/code.js` (CommonJS-модуль с
bytecode: `template`, `timelines`, `states`, `eventHandlers`), `designs/` с
исходниками, `package.json`. Редактор правит `code.js` через Babel AST.

## 3. Критично: телеметрия и утечки данных

Код **до сих пор** пытается отправлять данные на чужие серверы. Это нужно вырезать
первым делом (и ради приватности, и ради AGPL-чистоты форка).

| Что | Где | Что отправляет |
|---|---|---|
| Mixpanel в редакторе | `haiku-serialization/src/utils/Mixpanel.js` (захардкожены токены), ~20 вызовов | ОС, события, имена проектов, username |
| **Mixpanel в опубликованных компонентах** | `@haiku/core/src/Config.ts:24`, `HaikuDOMRenderer.ts:981` | Грузит `cdn.mxpnl.com` **в браузеры конечных пользователей** любого сайта с анимацией |
| Sentry (raven) | creator, glass, timeline, plumbing (DSN с секретом) | Крэши, email, имя и путь проекта. Включён по умолчанию, если `NODE_ENV` не задан |
| Carbonite | `haiku-sdk-creator/src/dal/Carbonite.ts` | **Zip всего проекта** в S3 Haiku при ошибках |
| Activity ping | `haiku-sdk-creator/src/bll/User.ts:51` | Токен логина |
| Right-click меню компонентов | `@haiku/core/.../createRightClickMenu.ts:110` | Org и имя проекта на `inkstone-edge.haiku.ai`, из браузеров конечных пользователей |

## 4. Мусор

### A. Удалить сразу (ничего не ломает)

- **Инфраструктура Haiku**: `Jenkinsfile`, `build.sh`, `generate_windows_installer.bat`,
  `_config.js.handlebars`, `scripts/distro-*`, `deploy.js`, `upload-cdn-core.js`,
  `git-subtree-*`, `push*.js`, AWS/Slack-хелперы, `hooks/` (Python 2.7), зависимости
  `aws-sdk`, `slack`, `@haiku/player`.
- **`haiku-admin-cli`**: внутренний инструмент сотрудников Haiku.
- **Старая документация**: `QA.md`, `articles/` (дамп мёртвого help-центра),
  `changelog/`, `PULL_REQUEST_TEMPLATE.md`, `ISSUE_TEMPLATE`.
- **Неиспользуемые файлы** (около 40, никто их не импортирует): `BranchesDrawer.js`,
  `EventsPane.js`, `OfflineExportUpgradeModal.tsx`, `Comment(s).js`,
  `CurrentTimelinePopover.js`, `CodebaseManager.ts`, хелперы и иконки в core и ui-common.
- **Фикстуры**: изначально считались мусором (~80 МБ), но проверка показала, что это
  рабочие сценарии: `yarn start` открывает проекты из `haiku-glass/test/projects` и
  `haiku-timeline/test/projects`, а `yarn demos` показывает все демо `@haiku/core` как
  галерею для ручной проверки рантайма. **Оставлены** (см. DECISIONS.md). Удалён только
  `Apr91` с чужим «All rights reserved».

> **Поправка после проверки (Фаза 0):** часть файлов из исходного списка
> «неиспользуемых» на деле используется: `@haiku/core/src/helpers/PRNG.ts` (тест),
> `haiku-testing/src/{assertions,mock}.ts` (тесты core, sdk-client, sdk-inkstone).
> Они оставлены. Список иконок в ui-common был с неверными именами — не трогали.

### B. Удалить после замены

- **`@haiku/sdk-inkstone`** (логин, проекты, биллинг Stripe, команды, шаринг)
  заменить локальными заглушками; затем убрать UI логина, paywall, trial,
  `LockoutModal`, `ShareModal`, Publish, прокси-экраны.
- **`@haiku/cli`**: оставить `init`/`generate`, остальное требует облака.
- **`@haiku/sdk-client`**: убрать запись `reservoir.haiku.ai` в `.npmrc` новых проектов.
- **Автообновление** (`releases.haiku.ai`, `squirrel.haiku.ai`): заменить на
  проверку GitHub Releases.
- **`haiku-vendor-legacy`**, **`haiku-fs-extra`**: копии npm-библиотек, заменить
  обычными зависимостями.
- **Фича-флаги**: 17 из 20 включены навсегда, их проверки можно убрать.

## 6. Недоделанное в коде

- **Таймлайн только один**: `getCurrentTimelineName()` — `TODO: Support many`.
- **Lottie-экспорт не поддерживает**: маски, clipPath, фильтры, текст, паттерны,
  градиенты на обводке, `gradientTransform`, квадратичные кривые и дуги в путях,
  анимацию opacity обёртки. **Баг**: `case Image` без `break`
  (`bodymovinExporter.ts:1207`).
- **Нет импорта Lottie** (просили в #1074).
- **Примитивы рисования есть, но не подключены**: `haiku-creator/src/react/primitives`
  (Rectangle, Ellipse, Polygon).
- **Bitmap-картинки** выключены флагом `AllowBitmapImages`.
- **Export-меню только для macOS**.
- **Expressions** вычисляются через `new Function`, поэтому не работают при строгом CSP.
- **Angular-адаптер**: пустые TODO.
- **Около 230 TODO/FIXME**; больше всего в `haiku-serialization` (77).

**Фаза 0 — Гигиена.** Вырезать телеметрию, Sentry, Carbonite и пинги (§3).
Удалить инфраструктуру Haiku, мусор и неиспользуемые файлы (§4A). Урезать фикстуры.

экран; Figma через personal access token; Export на всех ОС; баги undo и Lottie;

React-хуками и Vue 3; безопасный режим expressions.

**Фаза 5 — Новое.** Импорт Lottie и dotLottie, превью на ThorVG, тесты по
lottie-spec, маски, clipPath и текст в экспорте, импорт из Penpot, spring-easing,
state machine, инструменты рисования, новый бренд.
