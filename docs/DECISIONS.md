## 2026-10-11 — Итоги Фазы 0 (гигиена)

Сделано (каждый шаг — отдельный коммит, после каждого — сборка всех пакетов и тесты):
1. **Рантайм `@haiku/core`**: удалены Mixpanel (грузился на страницы конечных
   пользователей) и брендированное меню правой кнопки (ходило на inkstone-edge.haiku.ai).
   Опции `mixpanel`/`contextMenu` оставлены как устаревшие no-op для совместимости.
   Попутно исправлен краш при импорте под Node 21+ (`isIE` читал глобальный `navigator`).
2. **Редактор**: Mixpanel → пустой модуль; отправка в Sentry выключена в единой точке
   `shouldEmitErrors()`, DSN-ключи Haiku удалены; Carbonite больше не архивирует и не
   выгружает проекты; activity ping отключён.
3. **Инфраструктура Haiku** удалена: Jenkins, AWS/S3/CloudFront, Slack, git subtrees,
   релизные скрипты, Python 2-хуки (и шаг `yarn setup`, который стирал `.git/hooks`),
   `haiku-admin-cli`, лишние зависимости.
4. **Старая документация** удалена: QA.md, дамп help-центра, changelog Haiku, шаблоны.
5. **Неиспользуемые исходники редактора** (19 файлов) удалены после ручной проверки.

### Фикстуры оставляем
Тестовые и демо-проекты — это сценарии `yarn start` и галерея `yarn demos` для ручной
проверки рантайма, что важно при фокусе на веб-компонентах. Удаление не уменьшило бы
размер клона (файлы остаются в истории git), а историю не переписываем, чтобы сохранить
связь с upstream и авторство. Удалён только `Apr91` (чужой «All rights reserved»).

### Что осталось на следующие фазы
- Код Raven/Sentry, Inkstone, логина и paywall всё ещё в коде, но ничего не отправляет —
  полное удаление в Фазе 3 вместе с UI.
- npm-зависимости `mixpanel`, `raven`, `raven-js` убираются вместе с перегенерацией
  lockfile в Фазе 1.
- Мёртвые файлы внутри `@haiku/core` — при определении публичного API в Фазе 4.

## 2026-10-11 — Фокус и платформа

### Фокус: интерактивные веб-компоненты
Главный сценарий — интерактивные анимации для веба: рантайм `@haiku/core`, адаптеры
React/Vue/vanilla, states, expressions, actions.

Что из этого следует:
- `@haiku/core` модернизируем глубоко: ESM, без IE-кода, React 18+ на хуках, Vue 3,
  безопасный режим expressions (без `new Function`), никакой телеметрии в бандле.
- Развиваем интерактивность: модель State Machine (по образцу Rive), spring-easing.
- Lottie, GIF и MP4 остаются и поддерживаются, но не главный приоритет; Lottie-экспорт
  чиним (баги, корректность), новые фичи Lottie — позже.
- Angular-адаптер (Angular 6) — кандидат на удаление или переписывание; решить в Фазе 4.

### Платформа: остаёмся на Electron и обновляем его
Код сильно завязан на Node (plumbing, git, ffmpeg, файловая система). Поэтапное
обновление Electron до актуальной версии — самый быстрый путь к рабочим сборкам под
macOS (включая Apple Silicon), Windows и Linux. Tauri и веб-версию не рассматриваем на
этом этапе; можно вернуться к вопросу после Фазы 4.
